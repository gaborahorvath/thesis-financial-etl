Felhőalapú, automatizált pénzügyi ETL és BI platform (thesis-financial-etl)
Ez a repository Horváth Gábor „Felhőalapú, automatizált pénzügyi ETL és BI platform fejlesztése” című mérnökinformatikus BSc szakdolgozatának szoftverimplementációját tartalmazza. A rendszer egy 45+ nemzetközi tőzsdei instrumentumból álló portfólió-univerzum napi árfolyam- (OHLCV) és fundamentális adatait nyeri ki, tisztítja, számítja ki belőlük a technikai elemzési indikátorokat, majd idempotens módon betölti azokat egy felhőalapú PostgreSQL adatbázisba vezetői Power BI döntéstámogatás céljából.
Főbb funkciók és architektúra   Adatkinyerés (Extract): Napi OHLCV idősorok többszálas letöltése a Yahoo Finance (yfinance) felületéről, valamint vállalati fundamentális mutatók lekérdezése az Alpha Vantage REST API-n keresztül, exponenciális újrapróbálkozási (backoff) és Soft Error hibakezeléssel.   Adattranszformáció (Transform): Memóriaoptimalizált Pandas adattisztítás, tartományszűrés (domain validation) és a technikai indikátorok (SMA_20, SMA_50, SMA_200, EMA_12, EMA_26, RSI_14, MACD, MACD_Signal, MACD_Hist) ciklusmentes, vektorizált kiszámítása.   Adatbázis-betöltés (Load): Kötegelt (batch), atomi tranzakcióba zárt idempotens Upsert (INSERT ... ON CONFLICT DO UPDATE) betöltés felhőalapú Supabase PaaS PostgreSQL adatbázisba kötelező SSL/TLS (sslmode=require) titkosítással és futási KPI-naplózással.   CI/CD és minőségkapu (Orkesztráció): Szerver nélküli napi ütemezett futtatás (munkanapokon UTC 22:00-kor) GitHub Actions segítségével, GitHub Secrets titokkezeléssel és az éles betöltést megelőző automatizált PyTest egységteszteléssel.   Üzleti intelligencia (BI): Hibrid (Import és DirectQuery) kapcsolódású Microsoft Power BI vezetői dashboard egyedi DAX mérőszámokkal. 
Könyvtárstruktúra   .github/workflows/ – A napi automatizált adatfrissítést és a PyTest minőségkaput vezérlő GitHub Actions CI/CD konfiguráció (daily_etl.yml).   dashboard/ – A Power BI döntéstámogató felülethez tartozó DAX mérőszámok (powerbi_dax_measures.dax) és modell-elemek.   legacy_as_is/ – A manuális As-Is állapotot, valamint a futásiidő- és memóriaprofilozási (benchmark) méréseket reprezentáló scriptek.   sql/supabase_schema_and_rbac.sql – A PostgreSQL relációs sémát (instruments, daily_metrics, etl_audit_log), a CHECK kényszereket és a szerepköralapú hozzáférés-szabályozást (etl_writer_role, bi_reader_role) létrehozó SQL script.   src/ – A Python 3.11 ETL csővezeték objektumorientált forrásmoduljai:   extractor.py – MarketDataExtractor osztály a REST API kommunikációhoz és titokmaszkoláshoz.   transformer.py – FinancialDataTransformer osztály az adattisztításhoz és az indikátorok vektorizált számításához.   loader.py – PostgresDataLoader osztály az SQLAlchemy/psycopg2 alapú idempotens adatbázis-műveletekhez.   main.py – A teljes ETL életciklust összefogó és a futási metrikákat (idő, Peak RAM) mérő belépési pont.   tests/test_transformer.py – Determinisztikus PyTest egységtesztek (TC-01 – TC-06) a tisztítási, indikátorszámítási és Upsert logika verifikálására.   requirements.txt – A reprodukálható környezethez szükséges, rögzített verziójú Python csomagfüggőségek.
